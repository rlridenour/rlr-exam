A Typst package to produce exams that converts an Emacs Org Mode file to a formatted PDF exam with answer key.

* Overview

Write an exam once, in Org mode, and get two matching PDFs out of it: the
exam itself, and an answer key with correct multiple-choice answers marked
and sample essay answers printed in place.

The repository has three parts:

- =typst/= :: a Typst package (=exam=) providing the layout primitives
  (=exam-doc=, =section=, =mcq=, =essay=) that render a question set either
  as a blank exam or as a marked-up key.
- =elisp/ox-exam.el= :: an Emacs Lisp exporter that parses the constrained
  Org subset described below with =org-element-parse-buffer= and writes
  Typst source that calls into the package above. It registers a minimal
  =exam= backend so its commands show up under the export dispatcher
  (=C-c C-e=).
- =examples/sample-exam.org= :: a worked example.

* Requirements

- Emacs with Org mode (any reasonably recent Org; developed against Org's
  built-in =org-element= parser).
- The [[https://typst.app/][Typst]] CLI, on =PATH=, to compile the generated =.typ= files to PDF.

* Setup

Install the Typst package as a local package so generated files can
=#import "@local/exam:0.1.0"=:

#+begin_src sh
make install
#+end_src

This symlinks =typst/= to Typst's local package directory (=~/Library/Application
Support/typst/packages/local/exam/0.1.0= on macOS, =$XDG_DATA_HOME/typst/packages/local/exam/0.1.0=
on Linux). Run =make uninstall= to remove it.

If you'd rather not install the package, set =org-exam-typst-import= (in
your Emacs config) to a relative path instead, e.g.:

#+begin_src emacs-lisp
(setq org-exam-typst-import "../typst/lib.typ")
#+end_src

* Org file format

** Header

Four keywords are required at the top of the file:

#+begin_example
#+COURSE_NUMBER: MATH 101
#+COURSE_NAME: Calculus I
#+EXAM_NAME: Midterm 1
#+DATE: 2026-07-18
#+end_example

** Sections

Every level-1 headline is a section (e.g. "Multiple Choice", "Short
Essay"). Question numbering runs continuously across all sections, not
per section.

To start a section on a fresh page, give its headline a =:PAGEBREAK: t=
property:

#+begin_example
* Short Essay
  :PROPERTIES:
  :PAGEBREAK: t
  :END:
#+end_example

** Multiple choice

A section holds a numbered list. Each top-level item is a question; its
own numbered sub-list gives the options, in the order they should appear.
Mark the correct option with a literal trailing =*=:

#+begin_example
1. This is the first question
   1. Incorrect option
   2. Correct option*
   3. Incorrect option
   4. Incorrect option
#+end_example

Exactly one option per question must end in =*=; the exporter raises an
error if none or more than one does.

** Short essay

An item with no nested list is treated as an essay question. Give it a
=:SPACE:= property (how much blank writing space to leave on the exam,
e.g. =2in=, =3.5cm=) and, optionally, an =:ANSWER:= drawer with the text
to print in the key:

#+begin_example
1. Explain photosynthesis.
   :PROPERTIES:
   :SPACE: 3in
   :END:
   :ANSWER:
   Sunlight is converted into chemical energy in chloroplasts.
   :END:
#+end_example

=:SPACE:= is required. =:ANSWER:= is optional — omit it and the key will
say "(no answer key provided)".

Add =:PAGEBREAK: t= to give a long essay question a page of its own:

#+begin_example
1. Compare and contrast prokaryotic and eukaryotic cells.
   :PROPERTIES:
   :SPACE: 3.5in
   :PAGEBREAK: t
   :END:
#+end_example

** Page breaks

=:PAGEBREAK: t= works on a section headline (start the section on a new
page) and on an essay question (start that question on a new page).
Multiple-choice questions don't take one; they're already kept from
splitting across a page boundary.

The value may be =t=, =true=, =yes=, or =1= — or omitted entirely, since
=:PAGEBREAK:= on its own counts as true. =nil=, =false=, =no=, and =0=
turn it off; anything else is an error, so a typo won't be silently
ignored.

Breaks are honored in the exam only, never in the answer key: they exist
to give students room to write, and the key has no blank space to pad.
Consecutive breaks collapse rather than emitting a blank page, so a
section break followed immediately by a question break costs one page,
not two.

Under the shuffled-versions commands below, a section break stays with
its section (sections are never reordered) and a question break travels
with its question wherever the shuffle moves it.

** Inline formatting

=*bold*=, =/italic/=, and =~code~= inside question and option text carry
through to the Typst output. Everything else is treated as literal text
(math fragments like =$x^2$= are printed as-is, escaped, rather than
typeset as math).

* Usage

From within the Org buffer, either use the export dispatcher
(=C-c C-e X t= for Typst source, =C-c C-e X p= to also compile to PDF), or
call the commands directly:

- =M-x org-exam-export-to-typst= writes =<name>-exam.typ= and
  =<name>-key.typ= next to the Org file.
- =M-x org-exam-export-to-pdf= does the same and then runs =typst
  compile= on each, producing =<name>-exam.pdf= and =<name>-key.pdf=.

From the command line:

#+begin_src sh
make pdf FILE=examples/sample-exam.org
#+end_src

Try it on the bundled example with =make example=.

** Shuffled versions

To generate several variants of the same exam — same questions, different
order, with multiple-choice options independently reshuffled per question —
use =C-c C-e X v= (Typst source) or =C-c C-e X V= (also compiled to PDF),
or call the commands directly and enter how many versions you want when
prompted:

- =M-x org-exam-export-versions=
- =M-x org-exam-export-versions-to-pdf=

Each version gets a letter label (A, B, C, ...) and its own file pair:
=<name>-A-exam.typ= / =<name>-A-key.typ=, =<name>-B-exam.typ= /
=<name>-B-key.typ=, and so on. The label is also printed in the exam and
key headers next to the exam name, so graders can match a paper exam to
its key. The shuffle is seeded from the file name and version label, so
re-running the export on an unchanged file reproduces the exact same
versions — regenerating a lost key later will still match what was handed
out.

From the command line:

#+begin_src sh
make versions FILE=examples/sample-exam.org N=3
make versions-pdf FILE=examples/sample-exam.org N=3
#+end_src

(=N= defaults to 2 if omitted.)
